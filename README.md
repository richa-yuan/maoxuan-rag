# 遇事不决问毛选

一个以《毛泽东选集》为知识源的本地 RAG 问答应用。它把读书桌、文献检索与有出处的回答放在同一处，帮助人从经典中寻找方法，而不是寻找标准答案。

## 功能

- 本地中文检索：中文分词、同义词扩展、标题与主题加权、相关段落定位
- 精读回答：内置 10 篇精读选文，提供现实启发与可执行建议
- 全文阅读：按卷次、篇目浏览文献，搜索篇目或正文
- 引用溯源：回答附带原文出处，可查看命中段落与完整篇目
- 对话记录、文献收藏、Markdown 导出与回答偏好设置
- 响应式界面，支持桌面与移动端

## 本地运行

需要 Node.js 20 或更高版本。

```bash
npm install
npm run dev
```

打开终端输出的本地地址即可。

```bash
npm run build
npm run preview
```

## 导入自己的 EPUB

仓库不包含完整书籍正文，只保留可自由分发的应用代码与 10 篇精读内容。应用可以直接在这个精简知识库上运行。

如需使用自己的 EPUB 扩充知识库：

```bash
python3 scripts/import_epub.py /path/to/your-book.epub
npm run dev
```

导入脚本会读取 EPUB 目录结构，将各卷、篇目和正文写入 `public/data/library.json`。该文件已加入 `.gitignore`，不会误提交到仓库。

当前导入脚本针对具备 `toc.ncx` 目录的 EPUB，生成字段包括篇名、卷次、时期、正文与摘录。导入完成后，页面会显示全部篇目，并自动启用全文检索。

## 检索实现

检索完全在浏览器本地完成，问题不会上传到服务器：

1. 使用 `Intl.Segmenter` 对中文问题分词，并过滤无意义停用词
2. 根据问题意图扩展同义词与相关概念
3. 综合标题、主题、精读关键词与正文词频计算相关性
4. 在命中的篇目中定位相关段落，作为回答依据与阅读入口

核心实现见 [`src/search.js`](src/search.js)，精读内容见 [`src/data.js`](src/data.js)。

## 内容说明

本项目是阅读与检索工具，不代表对历史文本的完整收录或解释。应用中的回答由本地检索结果组织生成，请结合写作背景与自身处境独立思考。

仓库不分发完整书籍正文。引入或传播文献内容时，请遵守所在地区的法律、版权要求与出版方授权范围。
